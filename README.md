# КІБЕР — курс інструктора базового рівня (158 навчальний центр)

Навчальний веб-застосунок: лекції з озвучкою й паралельним текстом, тести, оціночний лист, тренажери «Опис цілі» та АПД. Працює офлайн.

- `src/lessons.py` — тексти занять і тести; `src/sheets.json` — критерії оціночних листів.
- `python3 src/build.py job` — тексти для озвучки → `tts/job.json` (озвучує GitHub Actions, `tts/run.py`).
- `python3 src/build.py html` — збирає `index.html`, `sw.js`, `manifest.webmanifest`, іконки.
